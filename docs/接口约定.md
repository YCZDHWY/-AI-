# 接口约定

第一版仅一台 plant-01，在可信局域网部署。Web 与 API 同源。

| HTTP 接口 | 行为 |
|---|---|
| GET /api/latest | mode、online、stale、broker_connected、reading；无数据 reading=null |
| GET /api/history?hours=24 | 1–168 小时，按时间升序，最多最近 10000 条 |
| POST /api/water | 当前固定 409；尚未实现水泵控制 |

数据接收时间 received_at 使用 UTC，浏览器本地显示。超过 45 秒无新采样判过期；真实模式还要求 broker 连通、设备在线。模拟和真实模式默认分别存储，不混用。

MQTT 主题：plant/plant-01/sensor（每 10 秒，不 retained）；plant/plant-01/status（retained，消息为 online 布尔值，设备使用离线遗嘱）。网关忽略 retained 传感器采样，不将旧数据当新数据。

```json
{"device_id":"plant-01","soil_raw":2300,"soil_percent":null,"temperature_c":24,"humidity_percent":60,"light_lux":650,"errors":[]}
```

soil_raw 0–4095；百分比 0–100；温度 -20–60；光照 0–120000。未标定的 soil_percent 为 null；采集失败对应值为 null，errors 提供错误码，不以 0 伪装正常。相对湿度百分比不是体积含水率。

## 第 7–12 周控制契约（待实现）

命令主题 plant/plant-01/cmd，含 command_id、duration_ms、expires_at、boot_id；结果主题 plant/plant-01/result，含 command_id、boot_id、state、reason 和实际运行时长。两类消息不 retained。状态上报届时增加本次启动的 boot_id。

设备拒绝重复编号、过期命令和旧启动标识。重连或网关重启不补发旧浇水命令；结果超时记未知，不自动重试。发布成功不等于执行成功，完成也不等于检测到了出水。

流量实测后由人确定单次时长、最短间隔和日累计上限，未设置则锁定；手动和自动均受限制。设备本地计时、看门狗、默认关闭电路需通过实测。控制功能实现前补充重复、超时、断网、异常与重启测试。
