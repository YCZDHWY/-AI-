# 硬件与部署

## 第一次开机

1. 下载 Orange Pi 4 Pro A733 对应的官方 Ubuntu 桌面镜像。不能用其它板型或普通 PC 镜像。读卡器插电脑，确认盘符；烧录会清空 TF 卡。用 balenaEtcher 写入并校验。
2. 借显示器、匹配接口的显示线和 USB 键鼠；笔记本 HDMI 一般是输出，不代替显示器。
3. 用配套 5V3A 电源启动，等首次扩容。其它充电头需验证稳定 5V3A 及线材兼容，不能凭 66W 标称判断。
4. 桌面连接手机 2.4GHz 热点，按实际镜像说明登录。此前手册默认 orangepi/orangepi，登录后用 passwd 修改密码。hostname -I 查询地址；电脑 ssh orangepi@板子IP，执行 python3 --version。SSH 不通查服务、IP 与热点隔离。
5. 记录镜像版本、IP、配网方法，不记录密码。正常关机后断电。

## 电脑与网关软件

电脑模拟运行见根目录 README；本地 Chart.js 不依赖 CDN。Linux 使用以下命令准备环境：

```bash
sudo apt update
sudo apt install python3-venv mosquitto mosquitto-clients
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn gateway.app:app --host 0.0.0.0 --port 8000
```

默认模拟模式。真实模式先用 sudo mosquitto_passwd -c /etc/mosquitto/passwd plant 交互创建 MQTT 密码。仅首次创建使用 -c，勿覆盖已有用户。设置文件可供 mosquitto 用户读取。编辑 /etc/mosquitto/conf.d/plant.conf：

```text
listener 1883
allow_anonymous false
password_file /etc/mosquitto/passwd
```

sudo systemctl restart mosquitto 后检查状态。仅在可信局域网使用，不映射公网端口；当前 MQTT 无 TLS。终端交互读取口令，不写入命令历史：

```bash
export PLANT_MODE=mqtt
export MQTT_HOST=127.0.0.1
export MQTT_USERNAME=plant
read -r -s -p "MQTT password: " MQTT_PASSWORD
export MQTT_PASSWORD
.venv/bin/python -m uvicorn gateway.app:app --host 0.0.0.0 --port 8000
```

手机访问 http://板子IP:8000，必要时仅对局域网开放 8000/1883。先终端运行；连续试运行前由软件 B 补 systemd、日志和自动重启验收，当前并非无人值守部署。

## ESP32 只读采集

Thonny 安装对应板型 MicroPython，设备 REPL 执行 import mip 后 mip.install("umqtt.simple")；设备需能联网，或电脑取得兼容模块后上传。将 config.example.py 复制为本地 config.py，填热点、MQTT 用户和口令；MQTT_HOST 填板子局域网 IP，不是 127.0.0.1。上传 config.py、main.py。config.py 已忽略，不提交密码。

普通 ESP32 默认参考接线：土壤 AO → GPIO34（ADC1），DHT11 DATA → GPIO27，BH1750 SDA → GPIO21、SCL → GPIO22；须按实际板图复核，不适用其它板型直接照搬。BH1750 默认 0x23，以扫描结果为准。

逐个验证传感器供电和输出电平；不将 5V 信号接入 ESP32。先确认模块在 3.3V 下正常，若需 5V 供电须核实电平转换。干湿土壤各测原始值，再填 SOIL_DRY/WET；未标定不显示百分比。探头电路不浸水；浮动 ADC 可能貌似正常，范围检查不能代替断线检测。

## 水泵前置检查

- 继电器须确认 3.3V 控制兼容和无回灌，上电/复位时默认关闭。否则换兼容模块或增加驱动级。
- 另备 USB 公母延长线或端子转接件，正线串 COM/NO，负线连续；固定和绝缘裸线，水泵电流不走细杜邦线。
- 水泵用独立 USB 电源，ESP32 调试用电脑，香橙派用配套电源。不同 USB 口未必隔离，MB102 不供泵。是否共地依实际驱动电路；触点隔离泵回路无需一律共地。
- 依据电机类型及厂家资料确认泵侧浪涌抑制；线圈保护不代表泵侧已保护。
- 准备水容器、量杯、托盘、管路固定件，水源低于出水端避免虹吸。约 1 秒有人看管点动、至少三次测量；不干转。再制定时长、间隔和累计上限。
- 当前固件只读传感器，未控制继电器。未完成上述验证前，不接完整无人值守水路。
