# 智能植物养护系统 · 采购清单

> 方案：Orange Pi 4 Pro（本地智能网关） + ESP32（感知与执行）
> 采购原则：先买核心跑通，再补配件，最后扩展。每种设备单价控制在 500 元以内。

## 一、第一笔 · 核心链路（先跑通再说）

- [ ] Orange Pi 4 Pro（4G）×1 —— 约 250–350 元 ｜ 本地智能网关
  - 下单前问卖家：能刷 Linux 镜像、CSI 摄像头可用、WiFi 正常
- [ ] ESP32-DevKitC 开发板 ×1 —— 约 25–40 元 ｜ 感知执行主控（认准 ESP32，别买成 ESP8266）
- [ ] 电容式土壤湿度传感器 ×2 —— 约 8–15 元/个 ｜ 务必选电容式，耐腐蚀
- [ ] DHT11 温湿度模块（模块版）×1 —— 约 5–10 元 ｜ 模块版自带上拉，省事
- [ ] BH1750 光照传感器 ×1 —— 约 8–15 元 ｜ I2C 数字输出
- [ ] 面包板 ×1 —— 约 10 元
- [ ] 杜邦线（公对公、公对母各一）×2 —— 约 15–25 元
- [ ] MicroSD 卡 32G（A2 级）+ 读卡器 ×1 套 —— 约 50–60 元 ｜ 刷 Orange Pi 系统

## 二、第二笔 · 执行与电源（把浇水跑起来）

- [ ] 5V 微型潜水水泵 ×1 —— 约 10–20 元 ｜ 执行浇水
- [ ] 6mm 硅胶水管 + 接头 ×1 套 —— 约 5 元
- [ ] 面包板电源模块 MB102 ×1 —— 约 10 元 ｜ 水泵独立供电，防主控重启

## 六、单买避坑提醒

1. DHT11 建议买模块版，自带上拉电阻；若买裸传感器需另配 4.7kΩ 上拉电阻。
2. 水泵必须独立供电（走 MB102 或单独适配器），通过继电器控制，并和 ESP32 共地（GND 接一起），否则容易重启或烧板。
3. 土壤湿度传感器认准电容式，电阻式便宜但用一两个月就腐蚀报废。
4. 主控认准 ESP32，别误买 ESP8266（WiFi 弱、跑 MicroPython 不顺）。
5. Orange Pi 电源接口先确认是 USB-C 还是 DC 圆口，按实际买，别买错接头。
6. 3 天验证线：拿到板子 3 天内做到"刷进系统 + 连上 WiFi + Python 读出传感器数据"，就继续用香橙派；卡死超 3 天且换镜像 / 换 USB 外设都救不回来，再启用退路买备胎。

## 七、香橙派使用不了的退路

- 退路一（就地解决）：换 Armbian / Ubuntu 社区镜像；WiFi 不稳插 USB 免驱网卡；CSI 不识别改用 USB 摄像头。
- 退路二（换备胎）：主板级故障（刷不亮、内存 / 存储故障）时，换树莓派 4（4G）或再买一块同款 Orange Pi。
- 退路三（极端情况）：第一阶段先用"ESP32 + 云端"把链路跑通，本地网关推迟采购，项目不卡死。

触发条件：拿到板子 3 天内做到"刷进系统 + 连 WiFi + Python 读出传感器数据"则继续用香橙派；任何一条卡死超 3 天且换镜像 / 换 USB 外设都解决不了，启动退路二。
